01

Что мы подключаем

Пошагово и в своём темпе

Eleven Music создаёт аудио по описанию. Бот получает данные пользователя, передаёт запрос сервису и отправляет получившийся аудиофайл в Telegram.

Пример: пользователь указывает имя, повод и настроение → бот просит создать поздравительную песню → отправляет результат.

Токен Telegram, ключ ElevenLabs и ключ OpenAI — разные секреты. Для создания музыки нужен ключ ElevenLabs. OpenAI может быть полезен для подготовки текста, но для самого подключения Eleven Music не обязателен.

02

Подготовьте всё необходимое

Пошагово и в своём темпе

  1. Откройте свой работающий проект Telegram-бота в Cursor. В этом гайде мы добавляем музыку в существующий проект.
  2. Убедитесь, что у вас есть доступ к аккаунту ElevenLabs. По документации Music API доступен пользователям платных подписок.
  3. Проверьте свой тариф, доступные кредиты и действующие условия до генерации. API использует ресурсы аккаунта; стоимость зависит от тарифа и использования.
  4. Сохраните работающую версию проекта через GitHub Desktop, чтобы к ней можно было вернуться.

03

Создайте секретный API-ключ

Пошагово и в своём темпе

  1. Войдите в ElevenLabs. В левом меню откройте Developers, затем вкладку API Keys.
  2. Запустите создание нового ключа, задайте ему понятное название, например telegram-music-bot.
  3. Если предлагаются ограничения доступа, выберите разрешение для работы с музыкой. Название пункта проверьте в своём окне: интерфейс может отличаться. При необходимости установите доступный лимит кредитов для ключа.
  4. Создайте ключ, скопируйте и сохраните его в безопасном месте. Полностью он отображается при создании.
Ключ никому не отправляйте: не вставляйте его в чат Cursor, не показывайте на видео и скриншотах. Если ключ показали или опубликовали, удалите его в ElevenLabs и создайте новый.

04

Добавьте музыку в проект через Cursor

Пошагово и в своём темпе

В Cursor откройте папку именно своего бота. Скопируйте запрос ниже в чат и отправьте без API-ключей.

Изучи мой существующий проект Telegram-бота, его библиотеку, сценарии и способ запуска. Добавь создание персональной песни через официальный Eleven Music API. Сохрани действующие функции, кнопки и стиль общения. Не заменяй проект целиком.

Сценарий: бот предлагает создать песню, спрашивает имя получателя, повод, для кого песня, пожелания и настроение. Подготовь понятный запрос к музыкальной модели на основе ответов. Сообщи, что генерация платная и может занять время, и перед отправкой запроса предложи пользователю подтвердить создание. После подтверждения создай песню с вокалом и отправь MP3 в Telegram как аудио. Вокал, русский язык, точное имя и слова проверь на реальном результате: не гарантируй их корректность заранее.

Используй официальный Eleven Music API и актуальную документацию. Явно задай модель music_v2 или music_v2_5 при её доступности в моём аккаунте; не выдавай наличие доступа за проверенное. Начни с короткого тестового фрагмента около 30 секунд; параметры сделай настраиваемыми. Учитывай, что запрос по одному описанию может не гарантировать вокал. Если для конкретного текста понадобится план композиции, объясни это и используй официальную схему соответствующей модели.

Добавь понятную обработку ошибок и повторную попытку по инициативе пользователя. Не запускай несколько генераций одновременно для одного пользователя, защити от повторных нажатий и сделай настраиваемый лимит запросов. Объясни, сбрасывается ли лимит после перезапуска. Не запускай платные генерации автоматически при старте и не проводи тестовый запрос за меня.

Считывай ключ из ELEVENLABS_API_KEY; существующий BOT_TOKEN и остальные настройки сохраняй. Секреты не записывай в код, GitHub, README или Dockerfile. Обнови зависимости, .env.example, .gitignore и инструкции. Проверь, что .env не отслеживается Git; если уже отслеживается, отдельно предупреди. Сохрани совместимость с имеющимся Dockerfile и Timeweb App Platform.

Проверь изменения доступными безопасными тестами без реальных платных запросов и расскажи простыми словами: какие файлы изменил, как добавить ключ в локальный .env и Timeweb, как запускать и проверять бота, как работают лимиты и какие есть ограничения. Не проси присылать ключи, не публикуй проект и не покупай услуги.
Готовый запрос по одному описанию не гарантирует, что песня будет с вокалом или что имя прозвучит правильно. Это проверяем после первой генерации.
05

Добавьте ключ на компьютере

Пошагово и в своём темпе

  1. Посмотрите ответ Cursor: он укажет файл локальных настроек вашего проекта. Обычно это .env в папке бота.
  2. Откройте его сами и добавьте строку ELEVENLABS_API_KEY=ваш_ключ, заменив слова после знака равенства своим настоящим ключом.
  3. Сохраните файл. Существующие переменные бота оставьте на месте.
  4. Убедитесь, что .env не включён в изменения для GitHub. Файл .env.example может содержать только пустой пример, без настоящего ключа.
На время ввода ключа остановите запись экрана. Не показывайте значение в чате, демонстрации или GitHub Desktop.
06

Проверьте песню в Telegram

Пошагово и в своём темпе

  1. Запустите бота способом, указанным Cursor. Если на сервере уже работает копия этого же бота, остановите её перед локальной проверкой.
  2. Откройте бота в Telegram, пройдите новый сценарий и подтвердите одну короткую генерацию.
  3. Дождитесь аудиофайла. Проверьте, воспроизводится ли он, есть ли вокал, насколько понятно звучит имя и подходят ли слова и настроение.
  4. Проверьте старые функции бота и расход кредитов в аккаунте ElevenLabs.
Не получили аудио? Передайте Cursor текст ошибки без ключей и токенов. Проверьте тариф, доступ Music API и разрешения ключа. Если песня пришла, но вокал или слова неточны, опишите результат в Cursor и корректируйте сценарий.
07

Сохраните проект на GitHub

Пошагово и в своём темпе

  1. Откройте GitHub Desktop и выберите репозиторий своего бота.
  2. В списке изменений убедитесь, что файла .env и других файлов с секретами нет. Если он уже был опубликован, отзовите соответствующие ключи и обратитесь к Cursor за помощью с очисткой проекта.
  3. Введите название изменений, например Добавлена генерация музыки, и нажмите Commit to main или кнопку для вашей ветки.
  4. Нажмите Push origin, чтобы отправить изменения на GitHub.
08

Добавьте ключ в Timeweb и проверьте запуск

Пошагово и в своём темпе

Если бот ещё не размещён, сначала создайте приложение по гайду Timeweb и проверьте выбранный регион и стоимость. Если приложение уже есть, откройте настройки его развёртывания.

  1. Найдите раздел «Переменные» и добавьте переменную с точным именем ELEVENLABS_API_KEY. Значение вставьте самостоятельно, не показывая на экране.
  2. Оставьте уже используемые ботом переменные, включая BOT_TOKEN. Убедитесь, что названия совпадают с теми, которые назвал Cursor.
  3. Сохраните настройки. При необходимости выполните обновление или повторное развёртывание приложения в соответствии с подсказками Timeweb.
  4. Остановите локальную копию бота. После запуска приложения откройте Telegram и проверьте старые функции, затем — одну генерацию песни.
Размещение и Music API оплачиваются отдельно. Проверка работы API из выбранного региона и права использования треков зависят от условий сервиса и тарифа.

Частые вопросы

Можно подключить музыку без OpenAI?

Да, для генерации аудио Eleven Music использует свой ключ. OpenAI нужен только если ваш проект отдельно использует его для текста или других задач.

Будет ли имя всегда произнесено правильно?

Гарантировать это нельзя. Проверьте первую песню; при необходимости измените запрос или написание имени. Точное следование тексту зависит от выбранной модели и настроек.

Почему бот не отвечает?

Проверьте, запущена ли одна копия, есть ли токен и ключ в нужном окружении, доступна ли музыка на тарифе. Передавайте Cursor ошибки без секретов.

Можно ли продавать песни?

Проверьте действующие условия ElevenLabs для вашего тарифа и сценария продажи перед запуском продукта.
